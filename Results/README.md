# Results

This directory contains the key simulation and hardware results of the RV-MAC FPGA implementation.

## Results Overview

### Architecture

`block_diagram.png`

System-level architecture of the 32-bit RISC-V processor with MAC and perceptron accelerators.

### Simulation Waveform

`waveform.png`

Simulation waveform showing the processor pipeline and accelerator-related signals during functional verification.

### Simulation Console Output

`console_output.png`

Console output from the Verilog simulation showing cycle-by-cycle processor, MAC, and perceptron activity.

### FPGA Hardware Output

`FPGA_output.jpg`

Photograph of the implemented RV-MAC design running on the target FPGA hardware.

## Result Categories

| Result | Description |
|---|---|
| Architecture | Overall processor and accelerator architecture |
| Waveform | RTL simulation results |
| Console Output | Simulation monitoring and debug output |
| FPGA Output | Hardware implementation and validation |

These results complement the detailed resource, timing, and power reports available in the [`Reports`](../Reports/) directory.
